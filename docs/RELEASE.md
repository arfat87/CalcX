# CalcX — Release, Deployment & Store Readiness

## 1. Release Artifacts Generated

The following production artifacts are generated by the Gradle build system:

1. **Release APK:**
   - Path: `app/build/outputs/apk/release/app-release.apk`
   - Size: **~1.5 MB**
   - Features: R8 code minification, unused resource shrinking, ProGuard optimizations.
2. **Production Android App Bundle (AAB):**
   - Path: `app/build/outputs/bundle/release/app-release.aab`
   - Size: **~3.6 MB**
   - Readiness: Formatted for Google Play Store Dynamic Delivery.
3. **Debug APK:**
   - Path: `app/build/outputs/apk/debug/app-debug.apk`
   - Size: **~18 MB**

---

## 2. Release Build Commands

```bash
# Clean project
gradle clean

# Run unit tests
gradle testDebugUnitTest

# Assemble Release APK
gradle assembleRelease

# Assemble Production Android App Bundle (AAB)
gradle bundleRelease
```

## 3. Signing Configuration

For continuous local testing and verification, the release build type is configured with the standard Android debug keystore signing config.

### Production Key Signing Checklist:
To sign with your private Google Play release keystore before Play Store upload:
1. Generate keystore (if not using Google Play App Signing):
   ```bash
   keytool -genkey -v -keystore calcx-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias calcx
   ```
2. Configure credentials in `gradle.properties` or environment variables:
   ```properties
   RELEASE_STORE_FILE=../calcx-release-key.jks
   RELEASE_STORE_PASSWORD=your_store_password
   RELEASE_KEY_ALIAS=calcx
   RELEASE_KEY_PASSWORD=your_key_password
   ```
